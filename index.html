📚 How to Play

1. Choose a cabinet: Click on any game machine icon to start that experiment.
2. Configure variables: Press the large green button selectors to set quantities, or adjust weights using the large [ + ] and [ − ] buttons.
3. Roll/Flip/Spin: Click the satisfying 1x, 10x, or 50x 3D arcade buttons. You will see the bars jump and the scores tick up instantly!
